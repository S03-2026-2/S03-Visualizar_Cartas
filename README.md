# S03-Visualizar_Cartas
Projeto da Matéria de Arquitetura de Software

Aplicação 4) Visualização de cartas
Responsável por exibir as cartas de cada jogador. Essa aplicação deve consultar os serviços de distribuição de cartas e de jogadores para recuperar as informações necessários sobre os jogadores e suas cartas, além de consultar a PokéAPI para recuperar as informações necessárias sobre os Pokémons.
